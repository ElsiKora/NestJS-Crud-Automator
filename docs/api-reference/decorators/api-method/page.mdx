# Method Decorators

`@ApiMethod` and `@ApiRouteCustom` compose method-level route metadata for controller methods that fall outside the auto-generated CRUD surface.

## When to use

- Use `@ApiMethod` when you only need low-level Nest route, Swagger, security, throttling, and metadata composition.
- Use `@ApiRouteCustom` when the route should also use the custom route runtime for request/response transformers, relation hydration/projection, subscribers, authorization result transforms, and serialization.
- Use generated `@ApiController` routes when the operation is standard CRUD.
