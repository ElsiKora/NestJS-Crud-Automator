# `@ApiRouteSubscriber`

Registers a class as a route-level subscriber for a specific entity. Subscribers intercept controller lifecycles (`before`, `after`, `error`) whenever an observable controller executes CRUD routes.

## Signature

```typescript
@ApiRouteSubscriber<E extends IApiBaseEntity>({
	actions?,
	authorization?,
	controllers?,
	entity,
	priority?,
	routes?,
}: IApiRouteSubscriberProperties<E>)
```

## Options

| Option                      | Description                                                                                                                                  |
| --------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| `actions`                   | Optional custom route action filters. Use with `@ApiRouteCustom`/custom action names.                                                        |
| `authorization.expectation` | Optional type-only route subscriber authorization expectation. `REQUIRED` narrows before-hook `authenticationRequest.authorizationDecision`. |
| `controllers`               | Optional controller class/factory filters when the same entity is served by multiple controllers.                                            |
| `entity`                    | Entity that the subscriber observes.                                                                                                         |
| `priority`                  | Execution order (higher runs first). Defaults to `0`.                                                                                        |
| `routes`                    | Optional generated CRUD route filters such as `EApiRouteType.CREATE` or `EApiRouteType.PARTIAL_UPDATE`.                                      |

## Usage steps

1. Add `@ApiControllerObservable()` to the controller that should emit events.
2. Extend `ApiRouteSubscriberBase<E>` and implement lifecycle hooks such as `onBeforeCreate`, `onBeforePartialUpdate`, `onAfterGetList`, or `onAfterErrorDelete`.
3. Decorate the subscriber class with `@ApiRouteSubscriber`.
4. Register the subscriber class as a Nest provider.

## Example

```typescript
@Injectable()
@ApiRouteSubscriber<PostEntity>({
	entity: PostEntity,
	priority: 10,
	routes: [EApiRouteType.CREATE],
})
export class PostAuditSubscriber extends ApiRouteSubscriberBase<PostEntity> {
	async onAfterCreate(context: TApiSubscriberRouteAfterCreateContext<PostEntity>) {
		this.logger.log("Post created", context.result);
		return context.result;
	}
}
```

Use `authorization.expectation` only when the observed route contract guarantees authentication and authorization. It does not add runtime guards; it only narrows route before-hook helper types when paired with the same `ApiRouteSubscriberBase`/context generic.
