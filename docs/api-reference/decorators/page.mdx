# Decorators

Every decorator exposed by NestJS CRUD Automator now has a dedicated reference page. Use this overview to decide which category to explore and jump directly to the detailed guides.

## How to choose the right decorator

### Controller decorators

Use these to configure controller-level behavior such as CRUD scaffolding, observability, and authorization requirements. Visit [/docs/nestjs-crud-automator/api-reference/decorators/api-controller](/docs/nestjs-crud-automator/api-reference/decorators/api-controller).

`@ApiController` also owns generated-read configuration. On generated GET and GET_LIST routes, `read.scope.parameters` maps every inherited controller-path parameter to a described direct scalar entity field. Automator then generates the PARAMETERS DTO and OpenAPI path parameters and conjunctively combines GET identity or GET_LIST query predicates with path scope and HOOKS/IAM scope. GET_LIST `request[QUERY]` owns typed filters, compound order, and optional PAGE/CURSOR pagination. These capabilities remain part of generated routes; use a custom method only when the operation is not an entity-backed read.

### Service decorators

Automate service CRUD implementations and enable subscriber observability at the service layer. Visit [/docs/nestjs-crud-automator/api-reference/decorators/api-service](/docs/nestjs-crud-automator/api-reference/decorators/api-service).

### Method decorators

Combine route metadata, guards, throttling, Swagger documentation, and custom-route runtime behavior for manual controller methods. Visit [/docs/nestjs-crud-automator/api-reference/decorators/api-method](/docs/nestjs-crud-automator/api-reference/decorators/api-method).

### Function decorators

Wrap repository operations inside services with consistent behavior, DTO typing, and subscriber hooks. Visit [/docs/nestjs-crud-automator/api-reference/decorators/api-function](/docs/nestjs-crud-automator/api-reference/decorators/api-function).

### Property decorators

Describe DTO fields in detail, enforce validation, and reuse entity metadata when building manual DTOs. Visit [/docs/nestjs-crud-automator/api-reference/decorators/api-property](/docs/nestjs-crud-automator/api-reference/decorators/api-property).

### Subscriber decorators

Register class-based subscribers that intercept controller or service lifecycles. Visit [/docs/nestjs-crud-automator/api-reference/decorators/api-subscriber](/docs/nestjs-crud-automator/api-reference/decorators/api-subscriber).

### Authorization decorators

Attach authorization policies that run before every generated route for a specific entity.  
Visit [/docs/nestjs-crud-automator/api-reference/decorators/api-authorization](/docs/nestjs-crud-automator/api-reference/decorators/api-authorization).
