# `@ApiFunctionGetList`

Provides the PAGE service/function path for paginated list retrieval with filtering, sorting, relation loading, counts, and GET_LIST function subscribers. Generated CURSOR routes use the existing decorated `getMany(...)` path instead and construct their flat envelope in the route runtime.

## Signature

```typescript
@ApiFunctionGetList<E extends IApiBaseEntity>(
	properties: IApiFunctionProperties<E>
)
```

Decorated methods gain the shape `getList(dto: TApiFunctionGetListProperties<E>): Promise<IApiGetListResponseResult<E>>`.

## Behavior

- Runs `onBeforeGetList` subscribers so they can modify the `FindManyOptions` (filters, joins, pagination).
- Uses `repository.findAndCount` or the active transaction manager repository to retrieve data and the total count.
- Computes `count`, `totalCount`, `totalPages`, and `currentPage` for the response DTO.
- Executes `onAfterGetList` subscribers, allowing them to reshape items or pagination metadata.
- Captures and rethrows HTTP exceptions while notifying `onBeforeErrorGetList` or `onAfterErrorGetList` subscribers.

## Example

```typescript
export class PostService {
	constructor(public repository: Repository<PostEntity>) {}

	@ApiFunctionGetList<PostEntity>({ entity: PostEntity })
	async getList(properties: TApiFunctionGetListProperties<PostEntity>) {
		return { items: [], count: 0, totalCount: 0, totalPages: 0, currentPage: 0 };
	}
}
```
