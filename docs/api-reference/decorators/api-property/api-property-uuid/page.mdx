# `@ApiPropertyUUID`

Describes UUID-based DTO fields and enforces RFC 4122 validation. Supports single identifiers or arrays with uniqueness constraints.

## Signature

```typescript
@ApiPropertyUUID(properties: TApiPropertyUuidProperties)
```

## Options

| Option                                               | Description                                                                                                                                                                                                        |
| ---------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `description`                                        | Defaults to `"identifier"` if omitted; appended to the entity name.                                                                                                                                                |
| `isArray`, `minItems`, `maxItems`, `isUniqueItems`   | Enables arrays of UUIDs with full validation. `isUniqueItems: true` rejects equal items without regard to case on a request array; see [Unique Items](/docs/nestjs-crud-automator/guides/validation#unique-items). |
| `isRequired`, `isNullable`, `isResponse`, `isExpose` | Standard property flags.                                                                                                                                                                                           |

## Behavior

- Generates a random UUID example for Swagger and sets the appropriate regex pattern/length. The pattern accepts exactly what `IsUUID()` accepts: versions 1 to 8, the nil and max UUIDs, in either letter case.
- Adds `IsUUID`, presence guards, `IsArray`, `ArrayMinSize`, `ArrayMaxSize`, and `ArrayNotEmpty` as needed.
- Writes request values in lower case, so an upper-case spelling names the same resource in IAM resource strings and in the database. Generated write routes also lower-case the bodies of `UUID` columns without a host pipe, so values are stored lower-case on every database; lower-case existing upper-case values in text columns once (see [Validation](/docs/nestjs-crud-automator/guides/validation#migration-notes)).
- Marks the Swagger schema with `format: uuid` and sets `example` or `[example]` for arrays.
- Adds `ApiResponseProperty`, `Expose`, or `Exclude` for response DTOs.

## Example

```typescript
class BulkDeleteDto {
	@ApiPropertyUUID({
		entity: UserEntity,
		description: "IDs to remove",
		isArray: true,
		minItems: 1,
		maxItems: 50,
		isUniqueItems: true,
	})
	ids!: Array<string>;
}
```
