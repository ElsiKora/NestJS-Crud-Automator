# `@ApiPropertyBoolean`

Applies Swagger metadata, validation decorators, and serialization logic for boolean DTO properties. Supports single values, arrays, nullable flags, and conversion of the exact text `"true"` and `"false"`.

## Signature

```typescript
@ApiPropertyBoolean(properties: TApiPropertyBooleanProperties)
```

## Notable options

| Option                                             | Description                                                                                                                                                                              |
| -------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `entity`                                           | Entity or factory returning the entity. Required so descriptions embed the entity name.                                                                                                  |
| `description`                                      | Field description appended to Swagger docs.                                                                                                                                              |
| `isRequired`                                       | Controls whether missing `undefined` values fail validation.                                                                                                                             |
| `isArray`, `minItems`, `maxItems`, `isUniqueItems` | Enables `boolean[]` with array validation. `isUniqueItems: true` rejects equal items on a request array; see [Unique Items](/docs/nestjs-crud-automator/guides/validation#unique-items). |
| `isNullable`                                       | Allows `null` while preserving strict `undefined` handling.                                                                                                                              |
| `isResponse`, `isExpose`                           | Controls whether `ApiResponseProperty`, `Expose`, or `Exclude` are emitted for response DTOs.                                                                                            |

## Behavior

- Adds `@ApiProperty` metadata with boolean schema details.
- Applies `IsBoolean` (with `{ each: true }` for arrays) and optional `IsArray`, `ArrayMinSize`, `ArrayMaxSize`, `ArrayNotEmpty`.
- Uses `class-transformer` `Transform` to convert `true`, `false`, the exact text `"true"` and `"false"`, and arrays of those into booleans. Any other value, such as `"1"`, `"0"`, `"no"`, `"TRUE"`, or a number, is left for `IsBoolean` to reject with `400`. A request property also carries `Type(() => Object)`, so the transform receives exactly the value the client sent, whatever the `@Expose` name of the property: a host pipe with `enableImplicitConversion` does not turn `"false"` or `"no"` into `true`. Before 5.0.0 `"1"`, `"0"`, and numbers were converted, and any other text became `true`.
- Preserves missing optional values as `undefined`/`null` instead of coercing them to `false` or `[false]`.
- Handles `isResponse` differently by adding `ApiResponseProperty` and skipping request validators.

## Example

```typescript
class UserFilterDto {
	@ApiPropertyBoolean({
		entity: UserEntity,
		description: "Active flag",
		isRequired: false,
	})
	isActive?: boolean;

	@ApiPropertyBoolean({
		entity: UserEntity,
		description: "Permission flags",
		isArray: true,
		minItems: 1,
		maxItems: 5,
		isUniqueItems: false,
	})
	flags!: boolean[];
}
```
