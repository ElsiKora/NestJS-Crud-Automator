# `@ApiPropertyNumber`

Adds Swagger metadata, validation, and serialization for numeric DTO properties. Supports integers, doubles, arrays, range limits, and multiple-of constraints with automatic example generation.

## Signature

```typescript
@ApiPropertyNumber(properties: TApiPropertyNumberProperties)
```

## Notable options

| Option                                               | Description                                                                                                                                                                                |
| ---------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `format`                                             | `EApiPropertyNumberType.INTEGER` or `DOUBLE`. Controls Swagger `type`/`format` and which validator (`IsInt` vs `IsNumber`) runs.                                                           |
| `minimum` / `maximum`                                | Value bounds enforced with `Min`/`Max`. Required to derive example defaults. For `INTEGER` they must stay within the safe integer range (see below).                                       |
| `multipleOf`                                         | Validates divisibility as an exact decimal (useful for currency increments).                                                                                                               |
| `exampleValue`                                       | Optional; falls back to a random value within the provided range. Accepts single value or array when `isArray` is `true`.                                                                  |
| `isArray`, `minItems`, `maxItems`, `isUniqueItems`   | Enables numeric arrays with full validation. `isUniqueItems: true` rejects equal items on a request array; see [Unique Items](/docs/nestjs-crud-automator/guides/validation#unique-items). |
| `isNullable`, `isRequired`, `isResponse`, `isExpose` | Control request validation, Swagger metadata, and serialization.                                                                                                                           |

## Behavior

- Registers `@ApiProperty` with the appropriate `type`, `format`, `minimum`, `maximum`, and `multipleOf`.
- Adds `Type(() => Object)` and `Transform` to request properties, so the transform receives exactly the value the client sent, whatever the `@Expose` name of the property and the host pipe options. Numbers are kept, canonical number text is converted (integer text only in canonical decimal form), and anything else, such as `"016"`, `true`, or a list given for a single-value property, is left for the validators to reject with `400`. A lone value for a list property, such as `?counts=7`, becomes the one-item list `[7]`; a comma list such as `?counts=1,2` is the single item `1,2`, which is rejected. Before 5.0.0 `Type(() => Number)` and `enableImplicitConversion` converted the value first, so a renamed property accepted `"016"` as `16` and `true` as `1`.
- Converts number text only where the request carries text: in a query, a path, and a form or multipart body. A JSON body must send a JSON number, so `{ "count": "5" }` fails `IsInt` (`count must be an integer number`) and `{ "count": 5 }` passes; a list checks each item. A property of a generated QUERY or PARAMETERS DTO converts; a hand-written DTO converts once a route reads it with `@Query()` or `@Param()`, and one class read from both a JSON body and a query or path fails at startup. No format is text in JSON: `INTEGER` and `DOUBLE` are OpenAPI `integer` and `number`, and a `bigint` column uses `ApiPropertyString` with `BIGINT_STRING`. See [Text And JSON Values](/docs/nestjs-crud-automator/guides/validation#text-and-json-values).
- For `INTEGER`, integer text is accepted only in canonical decimal form (`^-?(0|[1-9]\d*)$`). `016`, ` 16`, `0x10`, `16.0`, `1.6e1`, `1e3`, and `007` fail `IsInt` (`id must be an integer number`) instead of becoming `16` or `1000`. For `DOUBLE`, number text is accepted only as decimal text with an optional fraction and exponent (`^-?(0|[1-9]\d*)(\.\d+)?([eE][+-]?\d+)?$`): `1.5`, `-0.25`, `16.0`, and `1e2` are accepted; `""`, `" 16 "`, `0x10`, `+1`, `.5`, and `Infinity` fail `IsNumber`. Before 5.0.0 they became `0` or `16`.
- An `INTEGER` property whose `maximum` is above `Number.MAX_SAFE_INTEGER` or whose `minimum` is below `Number.MIN_SAFE_INTEGER` fails at startup, in `@ApiPropertyNumber` and in `@ApiPropertyDescribe`. A JavaScript number cannot hold such values exactly, so two different ids could parse to the same number. Describe a `bigint` column as `EApiPropertyDescribeType.STRING` with `format: EApiPropertyStringType.BIGINT_STRING`.
- Preserves missing optional values as `undefined`/`null` instead of coercing them to `NaN`.
- Applies `IsInt`/`IsNumber`, `IsDivisibleBy`, presence guards, `IsArray`, `ArrayMinSize`, `ArrayMaxSize`, and `ArrayNotEmpty` as needed.
- Adds `ApiResponseProperty` plus `Expose`/`Exclude` when `isResponse` is enabled.

## Example

```typescript
class PriceDto {
	@ApiPropertyNumber({
		entity: ProductEntity,
		description: "Price amount",
		format: EApiPropertyNumberType.DOUBLE,
		minimum: 0.01,
		maximum: 999999.99,
		multipleOf: 0.01,
		isRequired: true,
	})
	price!: number;
}
```
