# `@ApiPropertyString`

Provides comprehensive Swagger, validation, and transformation support for string DTO fields. Handles dozens of formats (email, URL, UUID, password, timezone, slug, etc.), arrays, regex patterns, and response serialization.

## Signature

```typescript
@ApiPropertyString(properties: TApiPropertyStringProperties)
```

## Key options

| Option                                               | Description                                                                                                                                                           |
| ---------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `format`                                             | Required `EApiPropertyStringType` value (STRING, EMAIL, URL, PASSWORD, UUID, REGEXP, PHONE_NUMBER, etc.). Determines validators such as `IsEmail`, `IsUrl`, `IsUUID`. |
| `pattern`                                            | Stringified RegExp (`"/^[a-z]+$/"`). Used by `Matches` and validated against `exampleValue`.                                                                          |
| `minLength` / `maxLength`                            | Enforced with `Length`.                                                                                                                                               |
| `isArray`, `minItems`, `maxItems`, `isUniqueItems`   | Enable string arrays with `IsArray`, `ArrayMinSize`, `ArrayMaxSize`, `ArrayNotEmpty`.                                                                                 |
| `isRequired`, `isNullable`, `isResponse`, `isExpose` | Control optionality, Swagger metadata, and serialization.                                                                                                             |
| `exampleValue`                                       | Single value or array; validated against the regex/length constraints.                                                                                                |

Use `GetDefaultStringFormatProperties(format)` when you want the package defaults for built-in formats instead of hand-maintaining `description`, `exampleValue`, `minLength`, `maxLength`, and `pattern`.

## Behavior

- Emits `@ApiProperty` with the correct format, pattern, and example. Arrays automatically wrap the schema in `items`.
- Adds format-specific validators pulled from `class-validator` (e.g., `IsEmail`, `IsPhoneNumber`, `IsStrongPassword`, `IsJWT`, `IsHexColor`).
- Registers request validators (`Matches`, `Length`, presence guards, array validators) unless `isResponse` is `true`.
- Applies `ApiResponseProperty`, `Expose`, or `Exclude` on response DTOs.

## Example

```typescript
class UserDto {
	@ApiPropertyString({
		entity: UserEntity,
		format: EApiPropertyStringType.EMAIL,
		...GetDefaultStringFormatProperties(EApiPropertyStringType.EMAIL),
		isRequired: true,
	})
	email!: string;

	@ApiPropertyString({
		entity: UserEntity,
		description: "Tags",
		format: EApiPropertyStringType.SLUG,
		minLength: 1,
		maxLength: 64,
		pattern: "/^[a-z0-9-]+$/",
		exampleValue: ["api", "docs"],
		isArray: true,
		minItems: 1,
		maxItems: 5,
		isUniqueItems: true,
	})
	tags!: Array<string>;
}
```

## BigInt string defaults

`EApiPropertyStringType.BIGINT_STRING` describes a decimal integer stored as a string. Use format-specific options when you need to restrict the sign:

```typescript
class AccountDto {
	@ApiPropertyString({
		entity: AccountEntity,
		format: EApiPropertyStringType.BIGINT_STRING,
		...GetDefaultStringFormatProperties(EApiPropertyStringType.BIGINT_STRING, {
			sign: EApiGetDefaultStringFormatPropertiesBigIntStringSign.UNSIGNED,
		}),
		isRequired: true,
	})
	balance!: string;
}
```

Supported `sign` members:

- `EApiGetDefaultStringFormatPropertiesBigIntStringSign.SIGNED` accepts zero, positive, and negative values. This is the default.
- `EApiGetDefaultStringFormatPropertiesBigIntStringSign.UNSIGNED` accepts zero and positive values.
- `EApiGetDefaultStringFormatPropertiesBigIntStringSign.NEGATIVE` accepts only negative values.
