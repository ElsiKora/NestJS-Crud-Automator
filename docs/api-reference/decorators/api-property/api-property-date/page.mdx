# `@ApiPropertyDate`

Formats, validates, and serializes date/time fields. Supports ISO date-time strings, date-only values, time-only values, and semantic identifiers (`CREATED_AT`, `UPDATED_AT`, etc.) used by auto DTOs.

## Signature

```typescript
@ApiPropertyDate(properties: TApiPropertyDateProperties)
```

## Key options

| Option                                               | Description                                                                                                                                                                                                |
| ---------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `identifier`                                         | `EApiPropertyDateIdentifier` describing semantic meaning. It drives default description text and generated write ownership for infrastructure timestamps.                                                  |
| `format`                                             | `EApiPropertyDateType.DATE`, `DATE_TIME`, or `TIME`. Controls regex pattern, example value, and expected serializer format.                                                                                |
| `isArray`, `minItems`, `maxItems`, `isUniqueItems`   | Enables arrays of date values with full validation. `isUniqueItems: true` rejects items at one instant on a request array; see [Unique Items](/docs/nestjs-crud-automator/guides/validation#unique-items). |
| `isRequired`, `isNullable`, `isResponse`, `isExpose` | Same semantics as other property decorators.                                                                                                                                                               |

## Behavior

- Emits `@ApiProperty` with the correct ISO example, pattern, and min/max lengths.
- Holds request values to the published form of `format` and adds `IsArray`, `ArrayMinSize`, `ArrayMaxSize`, and `ArrayNotEmpty` for request arrays. See [Request values](#request-values).
- Preserves missing optional array values as `undefined`/`null` instead of converting them to an empty array.
- Adds `ApiResponseProperty` and exposure decorators on response DTOs.
- Generated CREATE, UPDATE, and PARTIAL_UPDATE bodies omit properties identified as `CREATED_AT`, `RECEIVED_AT`, or `UPDATED_AT`, regardless of property name. Responses retain them; `DATE` and other business/range identifiers remain writable.

## Request values

A request value takes the form the OpenAPI pattern publishes, the same form a `GET_LIST` filter on the property takes:

| `format`    | Value                                      | After transformation |
| ----------- | ------------------------------------------ | -------------------- |
| `DATE`      | `YYYY-MM-DD` text for a day that exists    | The same text        |
| `DATE_TIME` | The UTC instant `YYYY-MM-DDTHH:mm:ss.sssZ` | A `Date`             |
| `TIME`      | `HH:mm:ss` text within one day             | The same text        |

`DATE` and `TIME` values are never turned into a `Date`, so a calendar day or a time of day is stored as sent in every process time zone. Type such a property as `string`. Any other value fails with `<property> must be in <form> format` (constraint `isDateFormatValue`, or `each value in <property> must be in <form> format` on an array). That covers a date-time without milliseconds, with an offset or without a zone, an impossible day such as `2026-02-30`, a number, and a one-element array on a single property. A valid `Date` on a `DATE_TIME` property is a server-side value and passes.

These are validators like the others. A request body is checked only where a host `ValidationPipe` validates it; a generated route without one stores the text as sent. `GET_LIST` filter values are checked by the route itself, with or without a pipe; see [Filtering and Sorting](/docs/nestjs-crud-automator/guides/filtering-and-sorting).

## Example

```typescript
class AuditDto {
	@ApiPropertyDate({
		entity: UserEntity,
		identifier: EApiPropertyDateIdentifier.CREATED_AT,
		format: EApiPropertyDateType.DATE_TIME,
		isResponse: true,
	})
	createdAt!: Date;

	@ApiPropertyDate({
		entity: UserEntity,
		identifier: EApiPropertyDateIdentifier.UPDATED_AT_FROM,
		format: EApiPropertyDateType.DATE,
		isRequired: false,
	})
	updatedAtFrom?: string;
}
```
