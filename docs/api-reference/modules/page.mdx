# Modules

Public Nest modules exported by NestJS CRUD Automator.

## ApiSubscriberModule

Discovers route and function subscriber providers.

**Location:** `src/module/api/subscriber.module.ts`

Use it once in the application module when route or function subscribers should execute:

```typescript
@Module({
	imports: [ApiSubscriberModule],
	providers: [PostAuditSubscriber, PostSlugSubscriber],
})
export class AppModule {}
```

Subscriber discovery only sees Nest provider instances. Importing the module is not enough by itself; register subscriber classes as providers and mark observed controllers/services with `@ApiControllerObservable()` or `@ApiServiceObservable()`.

## ApiAuthorizationModule

Wires the authorization runtime, guard, hooks policy discovery, IAM resolvers, simulator, bootstrap validation, and cache invalidation services.

**Location:** `src/module/api/authorization.module.ts`

```typescript
@Module({
	imports: [
		ApiAuthorizationModule.forRoot({
			cache: {
				mode: EApiAuthorizationCacheMode.SOURCE_FIRST,
			},
			hookPermissionSources: [hookPermissionSource],
			principalResolver,
		}),
	],
})
export class AppModule {}
```

Use `forRoot(...)` for value-based configuration and `forRootAsync(...)` when principal resolvers, permission sources, IAM attachment sources, or IAM document sources come from Nest providers.

Resolver caching defaults to `SOURCE_FIRST`: hooks permission, IAM attachment, and IAM document sources are read for every evaluation without cross-request map writes. `MEMORY` is an explicit process-local opt-in and requires positive `ttlMs` and `maxEntries` values. Invalid cache configuration fails during application bootstrap.
