# Utilities

Utility functions and helpers provided by NestJS CRUD Automator.

## Entity Utilities

### GenerateEntityInformation

Generates entity metadata from an entity class. The result includes TypeORM columns, relations, the primary key, and `@ApiPropertyDescribe` metadata discovered on the entity and its inherited base classes.

**Location:** `src/utility/generate-entity-information.utility.ts`

```typescript
function GenerateEntityInformation<E>(entity: IApiBaseEntity): IApiEntity<E>;
```

**Usage:**

```typescript
const entityInfo = GenerateEntityInformation(UserEntity);
// Returns: { tableName: "users", primaryKey: { name: "id", ... }, columns: [...] }
```

### GetEntityColumns

Gets all column names from an entity.

**Location:** `src/utility/get/entity-columns.utility.ts`

```typescript
function GetEntityColumns<E>(properties: IGetEntityColumnsProperties): Array<keyof E>;
```

**Internal Use:** Called automatically by controller factory.

### GetDefaultStringFormatProperties

Returns the default description, example, length bounds, and regex pattern for supported string formats.

**Location:** `src/utility/api/get-default-string-format-properties.utility.ts`

```typescript
function GetDefaultStringFormatProperties(format: TApiPropertyDefaultStringFormat): TApiPropertyDefaultStringFormatProperties;
```

**Usage:**

```typescript
const emailDefaults = GetDefaultStringFormatProperties(EApiPropertyStringType.EMAIL);

@ApiPropertyDescribe({
	type: EApiPropertyDescribeType.STRING,
	format: EApiPropertyStringType.EMAIL,
	...emailDefaults,
})
email!: string;
```

### DtoGenerate

Generates DTO classes from entity metadata.

**Location:** `src/utility/dto/generate/core.utility.ts`

```typescript
function DtoGenerate<E>(
	entity: ObjectLiteral,
	entityMetadata: IApiEntity<E>,
	method: EApiRouteType,
	dtoType: EApiDtoType,
	dtoConfig?: IApiControllerPropertiesRouteAutoDtoConfig,
	currentGuard?: Type<IAuthGuard>
): Type<unknown> | undefined;
```

**Internal Use:** Called automatically for DTO generation.

## String Utilities

### CamelCaseString

Converts a string to the package's PascalCase-style route/DTO name fragment.

**Location:** `src/utility/camel-case-string.utility.ts`

```typescript
function CamelCaseString(input: string): string;
```

**Example:**

```typescript
CamelCaseString("get_list"); // Returns: "GetList"
CamelCaseString("user_name"); // Returns: "UserName"
```

### CapitalizeString

Capitalizes first letter of string.

**Location:** `src/utility/capitalize-string.utility.ts`

```typescript
function CapitalizeString(input: string): string;
```

**Example:**

```typescript

```

## Authorization Utilities

- `AuthorizationDecisionApplyResult` applies an authorization decision's response transforms.
- `AuthorizationDecisionAttachResource` attaches resolved resources to a decision.
- `AuthorizationDecisionResolveFromRequest` reads an authorization decision from the authentication request.
- `AuthorizationPermissionMatches` and `AuthorizationPermissionSetMatches` compare permission strings and sets.
- `AuthorizationResolveDefaultPrincipal` resolves the default principal from an authentication request.
- `AuthorizationScopeMergeWhere` merges authorization scopes into TypeORM `where` options.

## Database Utilities

TypeORM helpers detect and explain common database errors:

- `DatabaseTypeOrmIsUniqueViolation`
- `DatabaseTypeOrmIsForeignKeyViolation`
- `DatabaseTypeOrmGetUniqueViolationDetails`
- `DatabaseTypeOrmGetForeignKeyViolationDetails`
- `DatabaseTypeOrmIsEntityNotFound`
- `DatabaseTypeOrmIsEntityMetadataNotFound`

## DTO Utilities

Public DTO helpers include generation, decorator, auto-context, manual child DTO, date handling, property marking, and cache-key helpers. Most are intended for advanced integrations with the generated DTO pipeline rather than normal application code.
