### EApiPropertyDateIdentifier

Date field identifiers.

```typescript
enum EApiPropertyDateIdentifier {
	CREATED_AT = "created",
	CREATED_AT_FROM = "createdAtFrom",
	CREATED_AT_TO = "createdAtTo",
	DATE = "date",
	EXPIRES_IN = "expiresIn",
	RECEIVED_AT = "receivedAt",
	RECEIVED_AT_FROM = "receivedAtFrom",
	RECEIVED_AT_TO = "receivedAtTo",
	REFRESH_IN = "refreshIn",
	UPDATED_AT = "updated",
	UPDATED_AT_FROM = "updatedAtFrom",
	UPDATED_AT_TO = "updatedAtTo",
}
```

`CREATED_AT`, `RECEIVED_AT`, and `UPDATED_AT` mark server-owned infrastructure timestamps. Generated CREATE, UPDATE, and PARTIAL_UPDATE body DTOs omit those identifiers while response DTOs retain them. `DATE` and the range/business identifiers do not imply write exclusion.

## GET_LIST Query Plan Enums

### EApiControllerGetListQueryPaginationMode

Selects the generated GET_LIST request, runtime, service path, and response envelope.

```typescript
enum EApiControllerGetListQueryPaginationMode {
	CURSOR = "cursor",
	PAGE = "page",
}
```

Omitted configuration defaults to PAGE. CURSOR is opt-in through `request[QUERY].pagination.mode`.

### EApiControllerGetListQueryUnlistedFields

Controls whether a configured GET_LIST filter/order section overlays the entity metadata baseline or acts as an allowlist.

```typescript
enum EApiControllerGetListQueryUnlistedFields {
	INHERIT = "INHERIT",
	REJECT = "REJECT",
}
```

### EApiControllerGetListQueryFilterMissingBehavior

Controls an enabled typed filter when its complete client group is absent.

```typescript
enum EApiControllerGetListQueryFilterMissingBehavior {
	OMIT = "OMIT",
	REJECT = "REJECT",
	USE_DEFAULT = "USE_DEFAULT",
}
```

`REJECT` produces `400 FILTER_REQUIRED`. `USE_DEFAULT` requires a typed static `defaultCondition`, inserts it only when the client omits that field group, and lets a supplied client group replace the default.

## Transaction Enums

### EApiFunctionTransactionMode

Shared transaction modes for generated routes, generated and custom functions, and function steps.

```typescript
enum EApiFunctionTransactionMode {
	MANDATORY = "MANDATORY",
	NONE = "NONE",
	REQUIRED = "REQUIRED",
	SUPPORTS = "SUPPORTS",
}
```

- `SUPPORTS` joins an active transaction if present and otherwise runs without one.
- `REQUIRED` joins an active transaction or opens a new one.
- `MANDATORY` requires an active transaction.
- `NONE` requires no active transaction.

Generated routes use the enum under `routes[routeType].transaction.mode`. Omitted route configuration behaves as `SUPPORTS` and does not open a route transaction.

```typescript

}
```

### EApiFunctionSubscriberTransactionExpectation

Subscriber-declared transaction expectations for function subscribers.

```typescript
enum EApiFunctionSubscriberTransactionExpectation {
	MANDATORY = "MANDATORY",
	NONE = "NONE",
	REQUIRED = "REQUIRED",
	SUPPORTS = "SUPPORTS",
}
```

`REQUIRED` and `MANDATORY` require `context.DATA.eventManager` before the subscriber hook runs. `SUPPORTS`, `NONE`, and omitted metadata keep the event manager optional; subscriber expectations do not create or forbid transactions.

### EApiRouteSubscriberAuthorizationExpectation

Subscriber-declared authorization typing expectations for route subscribers.

```typescript
enum EApiRouteSubscriberAuthorizationExpectation {
	OPTIONAL = "OPTIONAL",
	REQUIRED = "REQUIRED",
}
```

`REQUIRED` makes before-route subscriber helper types expose a required `context.result.authenticationRequest.authorizationDecision`. This is type-only metadata and does not add runtime authentication or authorization checks.
