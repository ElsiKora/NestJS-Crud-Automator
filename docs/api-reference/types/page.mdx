# Types

Key public type aliases exported by NestJS CRUD Automator.

## Service Function Types

```typescript
type TApiFunctionCreateProperties<E> = DeepPartial<E>;
type TApiFunctionUpdateProperties<E> = DeepPartial<E>;
type TApiFunctionDeleteCriteria<E> = FindOptionsWhere<E>;
type TApiFunctionGetProperties<E> = FindOneOptions<E>;
type TApiFunctionGetListProperties<E> = FindManyOptions<E>;
type TApiFunctionGetManyProperties<E> = FindManyOptions<E>;
```

`create` and `update` receive entity partials directly. They are not wrapped in `{ body }`, and `EntityManager` is not a public method argument.

## Route Query Types

```typescript
type TApiControllerGetListQuery<E> = {
	limit: number;
	orderBy?: keyof E;
	orderDirection?: EFilterOrderDirection;
	page: number;
} & Partial<TFilterKeys<E>>;
```

HTTP list queries use lowercase sort directions: `asc` and `desc`.

## Subscriber Context Helpers

```typescript
type TApiSubscriberFunctionBeforeCreateContext<E extends IApiBaseEntity, Result extends TApiFunctionCreateProperties<E> = TApiFunctionCreateProperties<E>, TTransactionExpectation extends EApiFunctionSubscriberTransactionExpectation = EApiFunctionSubscriberTransactionExpectation.SUPPORTS> = IApiSubscriberFunctionExecutionContext<E, Result, TApiSubscriberFunctionExecutionContextData<E, TTransactionExpectation>>;

type TApiSubscriberRouteBeforeCreateContext<E extends IApiBaseEntity> = IApiSubscriberRouteExecutionContext<
	E,
	{
		authenticationRequest?: IApiAuthenticationRequest;
		body: DeepPartial<E>;
		headers: Record<string, string>;
		ip: string;
	},
	IApiSubscriberRouteExecutionContextData<E, E>
>;
```

Prefer the exported helper types over manually spelling every generic parameter. Before function helpers accept an optional constrained `Result` generic for advanced cases where `context.result` is a stricter application payload. Function helpers also accept a transaction expectation generic; `REQUIRED` and `MANDATORY` narrow `context.DATA.eventManager` to `EntityManager` only when the expectation is known exactly. These generics are type-only and do not change validation, transformation, or runtime behavior.

## Function Subscriber Transaction Helpers

```typescript
type TApiSubscriberFunctionBaseBeforeDeleteResult<E, BeforeDeleteResultOrTransactionExpectation> = BeforeDeleteResultOrTransactionExpectation extends EApiFunctionSubscriberTransactionExpectation ? TApiFunctionDeleteCriteria<E> : Extract<BeforeDeleteResultOrTransactionExpectation, TApiFunctionDeleteCriteria<E>>;

type TApiSubscriberFunctionBaseTransactionExpectation<BeforeDeleteResultOrTransactionExpectation> = BeforeDeleteResultOrTransactionExpectation extends EApiFunctionSubscriberTransactionExpectation ? BeforeDeleteResultOrTransactionExpectation : EApiFunctionSubscriberTransactionExpectation.SUPPORTS;

type TApiSubscriberFunctionRequiredTransactionExpectation = EApiFunctionSubscriberTransactionExpectation.MANDATORY | EApiFunctionSubscriberTransactionExpectation.REQUIRED;

type TApiSubscriberFunctionTransactionData<TTransactionExpectation = EApiFunctionSubscriberTransactionExpectation.SUPPORTS> = [TTransactionExpectation] extends [TApiSubscriberFunctionRequiredTransactionExpectation] ? { eventManager: EntityManager } : { eventManager?: EntityManager };
```

These helper aliases power `ApiFunctionSubscriberBase` shorthand generics and `TApiSubscriberFunctionExecutionContextData`. Most applications should use the context helpers directly.

## Authorization Types

```typescript
type TApiAuthorizationRuleTransformPayload<E extends IApiBaseEntity> = Array<unknown> | boolean | E | IApiGetListResponseResult<E> | null | number | object | Partial<E> | Record<string, unknown> | string | undefined;
```

Authorization transforms receive the payload produced by the route action and may return a replacement payload of the same public response family.
