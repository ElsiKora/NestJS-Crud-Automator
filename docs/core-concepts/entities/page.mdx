# Entities

Entities are the foundation of your CRUD operations. By properly configuring entity properties with `@ApiPropertyDescribe`, you enable automatic DTO generation, validation, and Swagger documentation.

## Basic Entity Configuration

Every entity property that should participate in CRUD operations must be decorated with `@ApiPropertyDescribe`:

```typescript filename="product.entity.ts" copy
import { Entity, PrimaryGeneratedColumn, Column } from "typeorm";
import { ApiPropertyDescribe, EApiPropertyDescribeType, EApiPropertyStringType, EApiPropertyNumberType } from "@elsikora/nestjs-crud-automator";

@Entity("products")
export class ProductEntity {
	@PrimaryGeneratedColumn("uuid")
	@ApiPropertyDescribe({
		type: EApiPropertyDescribeType.UUID,
		description: "Product unique identifier",
	})
	id: string;

	@Column()
	@ApiPropertyDescribe({
		type: EApiPropertyDescribeType.STRING,
		description: "Product name",
		format: EApiPropertyStringType.STRING,
		minLength: 3,
		maxLength: 100,
		pattern: "/^.{3,100}$/",
		exampleValue: "Laptop",
	})
	name: string;

	@Column({ type: "decimal", precision: 10, scale: 2 })
	@ApiPropertyDescribe({
		type: EApiPropertyDescribeType.NUMBER,
		description: "Product price",
		format: EApiPropertyNumberType.DOUBLE,
		minimum: 0,
		maximum: 999999,
		multipleOf: 0.01,
		exampleValue: 999.99,
	})
	price: number;
}
```

## Property Types

### UUID Properties

Used for unique identifiers, typically primary keys:

```typescript
@PrimaryGeneratedColumn("uuid")
@ApiPropertyDescribe({
  type: EApiPropertyDescribeType.UUID,
  description: "Unique identifier",
})
id: string;
```

### String Properties

Text fields with various validation options:

```typescript
@Column()
@ApiPropertyDescribe({
  type: EApiPropertyDescribeType.STRING,
  description: "User email",
  format: EApiPropertyStringType.EMAIL,
  minLength: 5,
  maxLength: 255,
  pattern: "/^[\w-\.]+@([\w-]+\.)+[\w-]{2,4}$/",
  exampleValue: "user@example.com",
})
email: string;
```

Available string formats:

- `STRING` - Plain text
- `EMAIL` - Email addresses
- `URL` - URLs
- `PASSWORD` - Password fields (hidden in responses)

### Number Properties

Numeric fields with range validation:

```typescript
@Column()
@ApiPropertyDescribe({
  type: EApiPropertyDescribeType.NUMBER,
  description: "User age",
  format: EApiPropertyNumberType.INTEGER,
  minimum: 18,
  maximum: 120,
  multipleOf: 1,
  exampleValue: 25,
})
age: number;
```

Available number formats:

- `INTEGER` - Whole numbers
- `DOUBLE` - Decimal numbers

### Boolean Properties

Boolean flags:

```typescript
@Column({ default: false })
@ApiPropertyDescribe({
  type: EApiPropertyDescribeType.BOOLEAN,
  description: "Is user active",
})
isActive: boolean;
```

### Date Properties

Date and timestamp fields with automatic identifiers:

```typescript
@Column({ type: "timestamp", default: () => "CURRENT_TIMESTAMP" })
@ApiPropertyDescribe({
  type: EApiPropertyDescribeType.DATE,
  identifier: EApiPropertyDateIdentifier.CREATED_AT,
  format: EApiPropertyDateType.DATE_TIME,
})
createdAt: Date;

@Column({
  type: "timestamp",
  default: () => "CURRENT_TIMESTAMP",
  onUpdate: "CURRENT_TIMESTAMP"
})
@ApiPropertyDescribe({
  type: EApiPropertyDescribeType.DATE,
  identifier: EApiPropertyDateIdentifier.UPDATED_AT,
  format: EApiPropertyDateType.DATE_TIME,
})
updatedAt: Date;
```

Date identifiers express semantics rather than property names:

- Infrastructure timestamps: `CREATED_AT`, `RECEIVED_AT`, and `UPDATED_AT`.
- Writable business dates: `DATE`, `EXPIRES_IN`, and `REFRESH_IN`.
- Range/query identifiers: `CREATED_AT_FROM`, `CREATED_AT_TO`, `RECEIVED_AT_FROM`, `RECEIVED_AT_TO`, `UPDATED_AT_FROM`, and `UPDATED_AT_TO`.

Generated CREATE, UPDATE, and PARTIAL_UPDATE body DTOs omit the three infrastructure identifiers while response DTOs retain them. A property named `createdAt` remains writable when its identifier is `DATE`, and a nonstandard property name such as `insertedOn` is excluded when its identifier is `CREATED_AT`.

### Enum Properties

Enumeration types with predefined values:

```typescript
export enum UserRole {
  USER = "user",
  ADMIN = "admin",
  MODERATOR = "moderator",
}

@Column({
  type: "enum",
  enum: UserRole,
  default: UserRole.USER
})
@ApiPropertyDescribe({
  type: EApiPropertyDescribeType.ENUM,
  description: "User role",
  enum: UserRole,
  enumName: "UserRole",
})
role: UserRole;
```

### Object Properties

Complex nested objects with optional discriminator support:

```typescript
@Column({ type: "jsonb" })
@ApiPropertyDescribe({
  type: EApiPropertyDescribeType.OBJECT,
  description: "User metadata",
  dataType: UserMetadataDto,
  shouldValidateNested: true,
})
metadata: Record<string, unknown>;
```

For polymorphic objects with discriminator:

```typescript
@Column({ type: "jsonb" })
@ApiPropertyDescribe({
  type: EApiPropertyDescribeType.OBJECT,
  description: "Payment method",
  discriminator: {
    propertyName: "type",
    mapping: {
      card: CardPaymentDto,
      paypal: PayPalPaymentDto,
    },
  },
  dataType: [CardPaymentDto, PayPalPaymentDto],
})
paymentMethod: CardPayment | PayPalPayment;
```

## Inherited Entity Metadata

Entities may extend a shared base class that owns common TypeORM columns or `@ApiPropertyDescribe` metadata. DTO generation walks the entity inheritance chain, so inherited columns, primary keys, relations, and property metadata participate in validation and Swagger generation for the concrete entity.

```typescript
abstract class BaseContentEntity {
	@PrimaryGeneratedColumn("uuid")
	@ApiPropertyDescribe({
		type: EApiPropertyDescribeType.UUID,
		description: "Unique identifier",
	})
	id: string;

	@Column()
	@ApiPropertyDescribe({
		type: EApiPropertyDescribeType.STRING,
		description: "Shared slug",
		format: EApiPropertyStringType.STRING,
		minLength: 1,
		maxLength: 64,
		pattern: "/^[a-z0-9-]+$/",
		exampleValue: "intro-to-crud",
	})
	slug: string;
}

@Entity("articles")
export class ArticleEntity extends BaseContentEntity {
	@Column()
	@ApiPropertyDescribe({
		type: EApiPropertyDescribeType.STRING,
		description: "Article title",
		format: EApiPropertyStringType.STRING,
		minLength: 1,
		maxLength: 255,
		pattern: "/^.{1,255}$/",
		exampleValue: "Getting started",
	})
	title: string;
}
```

In this example, generated `ArticleEntity` DTOs include `id`, `slug`, and `title`. Inherited relation metadata is also registered as Swagger extra models when relation DTOs are generated.

### Relation Properties

Entity relationship metadata for route-configured loading:

```typescript
@ManyToOne(() => UserEntity, user => user.posts)
@ApiPropertyDescribe({
  type: EApiPropertyDescribeType.RELATION,
  description: "Post author",
})
author: UserEntity;

@OneToMany(() => CommentEntity, comment => comment.post)
@ApiPropertyDescribe({
  type: EApiPropertyDescribeType.RELATION,
  description: "Post comments",
})
comments: CommentEntity[];
```

## DTO Generation Control

Control which DTOs include specific properties:

```typescript
@Column()
@ApiPropertyDescribe({
  type: EApiPropertyDescribeType.STRING,
  description: "Internal admin notes",
  format: EApiPropertyStringType.STRING,
  minLength: 0,
  maxLength: 500,
  pattern: "/^[\\s\\S]{0,500}$/",
  exampleValue: "Visible to admins only",
  properties: {
    [EApiRouteType.CREATE]: {
      [EApiDtoType.BODY]: { isEnabled: false },
    },
    [EApiRouteType.UPDATE]: {
      [EApiDtoType.BODY]: { isEnabled: true },
      [EApiDtoType.RESPONSE]: { isEnabled: false, isResponse: true },
    },
  },
})
internalNotes: string;
```

## Validation Rules

Add custom validation behavior:

```typescript
@Column()
@ApiPropertyDescribe({
  type: EApiPropertyDescribeType.STRING,
  description: "Username",
  format: EApiPropertyStringType.STRING,
  minLength: 3,
  maxLength: 20,
  pattern: "/^[a-zA-Z0-9_-]+$/",
  properties: {
    [EApiRouteType.CREATE]: {
      [EApiDtoType.BODY]: { isRequired: true },
    },
  },
  exampleValue: "john_doe",
})
username: string;
```

## Guard-Based Visibility

Generate route/guard-specific response DTO metadata:

```typescript
@Column()
@ApiPropertyDescribe({
  type: EApiPropertyDescribeType.STRING,
  description: "Sensitive data",
  format: EApiPropertyStringType.STRING,
  minLength: 1,
  maxLength: 255,
  pattern: "/^[\\s\\S]{1,255}$/",
  exampleValue: "restricted",
  properties: {
    [EApiRouteType.GET]: {
      [EApiDtoType.RESPONSE]: {
        isExpose: true,
        isResponse: true,
        guard: { guards: [AdminGuard] },
      },
    },
  },
})
sensitiveData: string;
```

The `guard` metadata selects a generated DTO variant for routes protected by that guard. It does not inspect the current user's role at serialization time; runtime allow/deny decisions belong in Nest guards or authorization policies.
